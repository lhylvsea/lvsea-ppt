# Oh My PPT 图表适配

- 先判断数据关系是否需要图表；不能用装饰性图表替代没有证据的结论。
- 统一单位、轴含义、类别标签和数据来源；不要把 HTML 放进类别标签。
- 图表容器必须有明确高度，并把高度纳入标题、正文、脚注和安全余量的总预算。
- HTML 路线可使用 Chart.js，但数据和配置要保持确定性；动画只作用于容器或由 Chart.js 自身处理。
- 原生 PPTX 路线优先使用 `ppt-master` 的原生图表/形状能力；若降级为 SVG/PNG，必须在交付说明中写明编辑边界。
- 图表渲染失败时先检查事件、canvas id、容器高度和数据数组，不用第二份重复脚本掩盖问题。
