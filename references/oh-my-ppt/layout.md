# Oh My PPT 布局适配

## 页面决策顺序

先回答：页面 3 秒主旨是什么、页面角色是什么、观众先看什么/后理解什么/最后记住什么、哪些事实是主证据、页面密度是多少、适合哪种结构、各区块的宽高预算是多少。

## 可复用规则

- 页面是经过编辑的论证，不是来源文档的逐段搬运。
- 布局模式是结构参考，不是模板复制；视觉风格与版式结构分离。
- 先画出标题/主视觉/证据/结论/来源的区域，再写 HTML 或 SVG。
- 文字内容使用 grid/flex 或原生 PPTX 的明确区域；连接线、背景和装饰不能挤占文字预算。
- 独立模块必须有真实间距；不能靠 `overflow: hidden` 掩盖越界、碰撞或裁切。
- 高密度页面应合并同类事实、缩短标签、改用证据栏或矩阵，不用把所有事实都做成等权卡片。

## 画布换算

上游 HTML 16:9 规则通常以 1600x900 作为思考画布；`lvsea-ppt` 的 PPTX/SVG 执行器可使用 1280x720 或其他实际画布，但必须按比例重新计算安全区、标题区、主体区和来源区，不能直接复制像素数。

## 交付前检查

检查文本换行、标题可读性、卡片/图表是否越界、箭头是否穿过文字、页脚来源是否留出安全区，以及实际浏览器/PPTX 渲染结果是否与静态结构一致。
